# Aegaeon Brand Assets

This directory is the canonical source for Aegaeon brand assets. The admin
console (`aegaeon-admin-console-ui`) keeps its own build-time copies; when the
brand changes, update this directory first and propagate outward.

## Files

| File | Description |
|---|---|
| `aegaeon-mark.svg` | Logo symbol only (33x33 viewBox) |
| `aegaeon-logotype-white.svg` | Symbol + "Aegaeon" wordmark, white text (for dark backgrounds) |
| `aegaeon-logotype-dark.svg` | Symbol + "Aegaeon" wordmark, dark text `#0E0F15` (for light backgrounds) |
| `aegaeon-mark-512.png` | 512px raster of the symbol (favicons, slide decks, app icons) |
| `favicon.svg` | Browser favicon |

## Brand colors

| Token | Hex |

| aegisBlue | `#00B8FF` |
