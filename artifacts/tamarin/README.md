# Tamarin artifacts

This directory stores Tamarin verification artifacts that are useful as
evidence during reviews and compliance checks.

- Proof sources live under `proofs/tamarin/` (`*.spthy`).
- Logs in `artifacts/tamarin/manual/` are generated by running
  `tamarin-prover --prove` on each proof file (see `proofs/tamarin/run_tamarin.sh`).
- CI verification is driven by `nix build .#verify-tamarin`; this directory is
  for source-controlled snapshots of proof runs (human/audit friendly).
