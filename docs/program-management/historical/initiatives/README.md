# Historical Initiative Records

Last updated: 2026-07-08

Status: historical record

Owner: Program Management

Audience: maintainers, planning contributors

This directory contains completed initiative-level plans that are useful for
understanding past delivery decisions but no longer define active work.

## Scope

- completed initiative plans and closure summaries
- historical acceptance criteria for shipped work
- pointers from active initiatives to prior decision records

## Canonical Documents

- `[historical]` [JOSE initiative records](jose/README.md)

## Reading Rule of Thumb

1. Use active initiative directories for current planning.
2. Use this directory only when historical context is needed.
3. Promote durable implementation facts into `../../../specs/` or
   `../../../verification/`.
