# Grafana Dashboard (Sample)

Last updated: 2026-07-07

Status: current implementation baseline

Owner: Operations

Audience: operators, maintainers

This page provides a minimal sample Grafana dashboard JSON for Aegaeon metrics.

Canonical sample file:
- `docs/operations/monitoring/grafana.dashboards.sample.json`

## Import

1. In Grafana: **Dashboards → New → Import**
2. Upload `docs/operations/monitoring/grafana.dashboards.sample.json`
3. Select your Prometheus datasource and import.
