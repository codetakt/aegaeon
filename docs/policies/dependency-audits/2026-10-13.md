## Method and limits

Published crates.io archives were fetched through the pinned Cargo Vet tool and their SHA-256 values checked against the registry index. Delta reviews use the stated existing audit base. Review focused on changed executable code, unsafe invariants, dependency declarations, generated output, build scripts and ambient capabilities. A full review is explicitly marked below. Documentation-only and mechanically equivalent changes are identified in the notes.

These source reviews are not formal proofs, universal timing claims, or independent cryptographic validations. Cross-platform execution was not performed unless stated. No F*, Kani or Tamarin model changes are introduced for this dependency review and CSV parser replacement; the earlier CI results for the dependency update do not establish these reviews.

## CSV dependency disposition

The original `csv 1.4.0` archive is not certified. Aegaeon's only use now reads records through the already-reviewed `csv-core 0.1.13`. The small adapter keeps bytes in byte buffers, checks UTF-8 before creating strings, and preserves header validation, Unicode trimming, quoting, fixed column counts and row/line/byte diagnostics. Both product and fuzz lockfiles remove the unused wrapper. No vendored fork or exception is introduced.

The exact adapter matched the previous reader on 335,969 exhaustive/boundary inputs, including malformed quoting and Unicode. Four source tests cover invalid UTF-8 recovery, quoted newlines and growing record/field buffers. The server's isolated-process nextest run passed 2,057 tests, with 452 service/conditional tests skipped. A shared-process cargo-test run had seven tracing/environment-state failures; its original log is retained and is not presented as a passing run or a repaired concurrency issue. Clippy passed with warnings denied.
