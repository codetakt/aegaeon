## Implemented Solution

### Approach: Post-Build Archive Reconstruction

**File**: `nix/kani/package.nix` (lines 586-651)

**Strategy**: Use postFixup hook to rebuild libkani.rlib as metadata-only archives

```nix
postFixup = ''
  echo "=== Rebuilding libkani.rlib as metadata-only archive ==="

  # Process libkani-*.rlib files in both locations
  for lib_dir in "$out/kani-${version}/lib" "$out/kani-${version}/${hostLibDir}"; do
    if [ ! -d "$lib_dir" ]; then
      continue
    fi

    for rlib in "$lib_dir"/libkani-*.rlib; do
      if [ ! -f "$rlib" ]; then
        continue
      fi

      BASENAME=$(basename "$rlib")
      LIB_DIR_NAME=$(basename "$lib_dir")
      echo "Processing $BASENAME in $LIB_DIR_NAME..."

      # Create temporary directory for extraction (use /tmp instead of /build)
      WORKDIR=$(mktemp -d -t kani-rebuild-XXXXXXXXXX)

      # Extract archive contents (using ar from PATH)
      ar x "$rlib" --output "$WORKDIR"

      # Verify lib.rmeta exists
      if [ ! -f "$WORKDIR/lib.rmeta" ]; then
        echo "  ⚠ Warning: lib.rmeta not found in $BASENAME"
        rm -rf "$WORKDIR"
        continue
      fi

      # Count and remove object files (*.rcgu.o)
      OBJECT_COUNT=$(ls -1 "$WORKDIR"/*.rcgu.o 2>/dev/null | wc -l)
      if [ "$OBJECT_COUNT" -gt 0 ]; then
        echo "  Removing $OBJECT_COUNT object file(s) with metadata hashes"
        rm -f "$WORKDIR"/*.rcgu.o
      fi

      # Rebuild archive with only lib.rmeta (metadata-only)
      cd "$WORKDIR"
      ar crs libkani.rlib lib.rmeta
      cd - > /dev/null

      # Move to final location
      mv "$WORKDIR/libkani.rlib" "$lib_dir/"

      # Remove original hashed file
      rm -f "$rlib"

      echo "  ✓ Created libkani.rlib (metadata-only) in $LIB_DIR_NAME"

      # Clean up temporary directory
      rm -rf "$WORKDIR"
    done
  done

  # Verify the result
  echo ""
  echo "=== Verification ==="
  for lib_dir in "$out/kani-${version}/lib" "$out/kani-${version}/${hostLibDir}"; do
    if [ -f "$lib_dir/libkani.rlib" ]; then
      echo "Archive contents of $lib_dir/libkani.rlib:"
      ar t "$lib_dir/libkani.rlib"
    fi
  done
'';
```

### Why This Solution Works

1. **Extracts metadata**: Uses `ar x` to extract archive contents
2. **Removes hashed objects**: Deletes all `*.rcgu.o` files containing metadata hashes
3. **Rebuilds with metadata only**: Creates new archive with only `lib.rmeta`
4. **Matches official structure**: Result is identical to official Kani 0.66.0 release
5. **Preserves patchelf**: Runs after standard fixup, so patchelf is already applied
6. **Minimal changes**: Only modifies the problematic archive structure

### Implementation Details

#### Location Handling
Processes libkani.rlib in both:
- `$out/kani-0.66.0/lib/libkani.rlib`
- `$out/kani-0.66.0/lib/rustlib/x86_64-unknown-linux-gnu/lib/libkani.rlib`

#### Temporary Directory
Uses `mktemp -d -t kani-rebuild-XXXXXXXXXX` to create temp dir in `/tmp` (not `/build`, which doesn't exist during fixup phase)

#### Error Handling
- Checks directory existence before processing
- Verifies lib.rmeta presence before rebuilding
- Warns if unexpected archive structure found

#### Verification
Build output shows:
```text
=== Rebuilding libkani.rlib as metadata-only archive ===
Processing libkani-ef1073637ed45e71.rlib in lib...
  Removing 1 object file(s) with metadata hashes
  ✓ Created libkani.rlib (metadata-only) in lib

=== Verification ===
Archive contents of .../lib/libkani.rlib:
lib.rmeta
```

## Differences from Official Kani Environment

### Official Kani (cargo install kani-verifier)

| Aspect | Official Kani |
|--------|--------------|
| **Build Method** | `cargo build` with custom flags via `tools/build-kani` |
| **Metadata Hash** | None (no `-C metadata=` flag) |
| **libkani.rlib Structure** | Metadata-only (lib.rmeta only) |
| **Installation** | Via rustup custom toolchain |
| **Library Location** | `~/.rustup/toolchains/kani-0.66.0/lib/` |
| **Object Files** | None in archive |

### NixOS Build (this project)

| Aspect | NixOS Build |
|--------|-------------|
| **Build Method** | `buildRustPackage` with standard Nix infrastructure |
| **Metadata Hash** | Auto-generated by cargo (e.g., `ef1073637ed45e71`) |
| **libkani.rlib Structure** | **Before fix**: Full library (lib.rmeta + hashed objects); **After fix**: Metadata-only (lib.rmeta only) ✅ |
| **Installation** | Via Nix store |
| **Library Location** | `/nix/store/.../kani-0.66.0/lib/` |
| **Object Files** | **Before fix**: `kani-<hash>.kani.<hash>-cgu.0.rcgu.o`; **After fix**: None (removed by postFixup) ✅ |
