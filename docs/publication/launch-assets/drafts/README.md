This directory contains unapproved publication collateral drafts. Keep these
separate from launch schedules and current product-positioning sources so OSS
readers do not mistake working copy for released wording.

## Scope

- event and booth collateral drafts
- follow-on release announcement drafts
- partner-facing publication drafts
- v0.1.0 landing-page, press-release, and spec-sheet drafts

## Draft Lifecycle Rule

- Promote approved wording into `../v0.1.0/` or the relevant publication package.
- Delete rejected or stale drafts once their useful wording has been promoted.
- Keep dated draft files only while an active launch package or review thread uses them.

3. Promote approved durable wording out of `drafts/`; leave rejected drafts to Git history.
