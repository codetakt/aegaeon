# Aegaeon v0.1.0 Preview Request Flow

Last updated: 2026-07-08

Status: draft

Owner: Product / Publication

Audience: publication contributors, maintainers

> **Status note (2026-07-08):** Draft publication collateral; do not treat this as approved release wording, and check `docs/product-positioning.md` before reuse.

This draft covers the public-facing evaluation / preview inquiry path for the first launch.

## Form goal

- capture serious evaluation interest
- separate media / partnership / technical evaluation intent
- collect enough context for fast follow-up without making the form too heavy

## Form title

Aegaeon Preview / PoC Consultation Request

## Intro copy

If you are considering an Aegaeon evaluation or PoC, we welcome requests for preview information and individual consultations.
Share your intended use case and current challenges so we can suggest a suitable way forward.

## Required fields

- Full name
- Company / organization name
- Email address
- Role
  - Executive / business leader
  - Product leader
  - Engineering leader
  - Security / IT administrator
  - Developer
- Inquiry type
  - I would like to try the preview
  - I would like to discuss a PoC
  - I would like to discuss adoption
  - I would like to discuss a partnership / collaboration
- Intended use case
- Current challenges

## Optional fields

- Expected adoption timeframe
- Number of users / tenants in scope
- Requirements
  - Self-hosted
  - Audits
  - Key operations
  - Federation
  - Educational use
  - Enterprise integration
- Supporting materials / URLs

## Consent block

- Consent to the privacy policy
- Consent to receive communications about evaluation and adoption consultations

## Internal routing suggestion

- `I would like to discuss adoption`:
  - highest priority
- `I would like to discuss a PoC`:
  - technical discovery route
- `I would like to try the preview`:
  - nurture / self-serve route
- `Partnership / collaboration`:
  - business development route

## Thank-you page copy

Thank you for your request.
A team member will contact you after reviewing the details.
Please also take a look at the whitepaper and Spec Sheet.

- route submissions into a shared mailbox or CRM queue
- keep a fixed response SLA
