# Aegaeon v0.1.0 Preview Request Flow

Last updated: 2026-07-08

Status: draft

Owner: Product / Publication

Audience: publication contributors, maintainers

> **Status note (2026-07-08):** Draft publication collateral; do not treat this as approved release wording, and check `docs/product-positioning.md` before reuse.

This draft covers the public-facing evaluation / preview inquiry path for the first launch.

## Form goal

- capture serious evaluation interest
- separate media / partnership / technical evaluation intent
- collect enough context for fast follow-up without making the form too heavy

## Form title

Aegaeon プレビュー版 / PoC 相談申し込み

## Intro copy

Aegaeon の評価や PoC をご検討中の方向けに、プレビュー版のご案内と個別相談を受け付けています。
導入予定のユースケースや現在の課題を共有いただければ、適した進め方をご案内します。

## Required fields

- 氏名
- 会社名 / 組織名
- メールアドレス
- 役割
  - 経営 / 事業責任者
  - プロダクト責任者
  - エンジニアリング責任者
  - セキュリティ / IT 管理者
  - 開発担当
- お問い合わせ種別
  - プレビュー版を試したい
  - PoC を相談したい
  - 導入を前提に相談したい
  - パートナー / 協業について相談したい
- 想定ユースケース
- 現在の課題

## Optional fields

- 想定導入時期
- 対象ユーザー数 / テナント数
- 必要な要件
  - Self-hosted
  - 監査
  - 鍵運用
  - Federation
  - 教育用途
  - エンタープライズ統合
- 補足資料 / URL

## Consent block

- プライバシーポリシーへの同意
- 評価・導入相談に関する連絡を受け取ることへの同意

## Internal routing suggestion

- `導入を前提に相談したい`:
  - highest priority
- `PoC を相談したい`:
  - technical discovery route
- `プレビュー版を試したい`:
  - nurture / self-serve route
- `パートナー / 協業`:
  - business development route

## Thank-you page copy

お申し込みありがとうございます。
内容を確認のうえ、担当者よりご連絡します。
あわせて、ホワイトペーパーと Spec Sheet もご参照ください。

### Body

先にご確認いただける資料:

- ホワイトペーパー
- Spec Sheet
- GitHub リポジトリ

## Operational notes

- route submissions into a shared mailbox or CRM queue
- keep a fixed response SLA
- test the form and thank-you flow before the press release goes live
