# Launch Assets

Last updated: 2026-07-08

Status: active plan

Owner: Product / Publication

Audience: publication contributors, maintainers

This directory indexes launch-material entrypoints for Aegaeon's 2026 public
release sequence. Approved schedules and current references stay here; unapproved
collateral belongs under `drafts/`.

## Scope

- `v0.1.0/` — first-public-release launch schedule and package entrypoint
- `drafts/` — unapproved publication, event, partner, and design collateral

## Current References

Read these before editing launch copy:

- `v0.1.0/aegaeon-pr-plan-2026.md` - active launch schedule and release plan
- `../../product-positioning.md` - canonical outward-facing wording and boundary limits
- `../../development/current-delivery-context.md` - current shipped surface and admin-console boundary
- `../../verification/claims/formal-claim-overview.md` - formal claim boundary and assumptions

## Canonical Documents

- `[index]` `v0.1.0/README.md` - first-public-release launch package
- `[draft]` `drafts/README.md` - unapproved publication collateral drafts

## Reading Rule of Thumb

1. If a launch-material draft conflicts with `docs/product-positioning.md` or the assurance docs,
   the boundary docs win.
2. Launch copy may simplify wording, but it must not widen the current claim.
3. Keep unapproved copy under `drafts/` until it is promoted into an approved package.
