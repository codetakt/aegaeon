# Publication Overview

Last updated: 2026-07-08

Status: active plan

Owner: Product / Publication

Audience: publication contributors, maintainers

This directory contains outward-facing publication materials and launch drafts.
Use it for website copy, press material, event collateral, and public-readiness
checklists that are derived from the current product and verification wording.

## Scope

- launch-page and landing-page copy
- press, event, and handout drafts
- public-readiness checklists and asset status notes
- preview request and publication-rollout support material

## Canonical Documents

- `[publication]` [Launch assets index](launch-assets/README.md)
- `[policy]` [Product positioning](../product-positioning.md)
- `[index]` [Release evidence overview](../releases/README.md)

## Reading Rule of Thumb

1. Start with `../product-positioning.md` before changing public claims.
2. Use `launch-assets/README.md` for launch entrypoints and `launch-assets/drafts/README.md`
   for unapproved collateral.
3. Treat publication drafts as derived material; update the source spec or
  verification document first when the underlying claim changes.
